# LP Range Designer

Uniswap V3 型の集中流動性ポジションについて、**実現ボラティリティ（σ）と実測の値動き**からレンジ幅を決め、その妥当性を検証するための単一HTMLの計器です。ビルド不要・外部ライブラリ依存なしで、ブラウザで開くだけで動作します。

**公開ページ**: https://mflab-inc.github.io/LP-Range-Designer/
**ローカル実行**: このリポジトリの `index.html` をブラウザで直接開いても、内容・挙動は同一です。

## これは何をするツールか

「レンジ幅は相場観ではなくσ（値動きの大きさ）で決める」「ペア・資産ごとに別々に設計する」という考え方に基づき、以下を計算・表示します。

- 選んだレンジ幅で、価格がレンジ外に出るまでの期待日数
- フルレンジ（V2型）と比べた資金の集中倍率
- 手数料収入の年率概算 と 値動きに由来するコストの年率概算（どちらが上回るかの目安）

出力はすべて過去データに基づく**近似・目安**であり、将来の値動きや運用成果を保証・示唆するものではありません。売買の助言でもありません。

## 3つのモード

| モード | 何をするか |
|---|---|
| **設計する** | 現在価格・日次σ・目標滞在日数などを入力すると、推奨レンジ幅と期待滞在日数を計算する |
| **既存レンジを検証** | 運用アプリ上のMin/Maxを入力すると、実効半幅・幾何中心・集中倍率・そのσでの期待滞在を逆算する |
| **中期設計** | 日足CSV（CoinMarketCap形式）を読み込み、過去の実測経路の経験分位からレンジ幅を決める。対HODL比較のバックテストも表示 |

「設計する」「検証」はガウス近似（後述②式）に基づく概算、「中期設計」は実測の値動きの分布（経験分位）に基づく概算で、それぞれ独立した方法です。

## 計算式

| # | 式 | 内容 |
|---|---|---|
| ① | 半幅（上）= k·σ·√T、半幅（下）= 半幅（上）×下方スキュー | k: 安全係数（既定1.4）。下方スキューは下振れリスクを厚めに見る係数（既定1.25） |
| ② | 期待滞在日数 ≈ (半幅 ÷ σ)² | 無ドリフト近似。トレンドが発生すると実際の滞在日数はこれより短くなる |
| ③ | 集中倍率 ≈ 1 ÷ (1 − (下限/上限)^¼) | フルレンジ（V2型）と比べて資金を何倍濃く置けるかの目安 |
| ④ | 実効APR ≈ (24h出来高 × 手数料率 ÷ TVL) × 365 × 集中倍率 × 稼働率 | 手数料収入の年率換算の概算 |
| ⑤ | ボラ由来コスト ≈ (σ² ÷ 8) × 365 × 集中倍率 | 値動きにより生じるコストの年率概算（LVR系）。④が⑤を上回ることが損益分岐の目安 |

**経験分位バンド**（中期設計モード）: 指定した保有期間について、過去の各エントリー日から実際に生じた最大上振れ・最大下振れを集計し、指定した被覆率（例: 90%）に収まる幅を上下独立に求めたものです。②式のガウス近似には依存せず、実際の値動きの歴史を物差しにした概算です。

## データについて

- 価格データの取得元: [CoinMarketCap](https://coinmarketcap.com/)（日足CSVを取り込んで実測σ・経験分位バンドを計算）
- プールの出来高・TVL・手数料階層は [GeckoTerminal](https://www.geckoterminal.com/) の公開APIから自動取得（`data via GeckoTerminal`）。取得できない場合は手入力に切り替わります
- 読み込んだCSVやAPI取得値はページ内メモリにのみ保持され、保存されません。ページを閉じると消えます（このHTMLはlocalStorage等を使用しません）

## 免責事項
